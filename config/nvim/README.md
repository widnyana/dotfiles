# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

## This config's customizations

- [docs/plugins.md](./docs/plugins.md) — what each plugin (LazyVim extra or repo-local) is for
- [docs/keybindings.md](./docs/keybindings.md) — everything this repo adds or changes on top of LazyVim's default keymap
